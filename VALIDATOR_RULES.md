# Validator rules

Generated by `scripts/gen_validator_rules.py`. Do not edit by hand.

Each validator below is listed with the notice codes it can emit and the
severity of each. A code marked **canonical** is defined by the
[Canonical GTFS Schedule Validator](https://gtfs-validator.mobilitydata.org/rules.html)
and matches its severity; the rest are ours, and by policy none of them is
ERROR — a code MobilityData does not define is our opinion, and an opinion
should not fail someone's feed.

176 codes, 133 of them canonical.
